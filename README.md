# Heavenly Bespoke Studio

# BUILD BRIEF — HEAVEN FURNITURE MART

## Premium Conversion-Focused Landing Page for RACDOX Hackathon

Build a **single, premium, conversion-focused landing page** for **Heaven Furniture Mart**, a luxury/bespoke furniture brand based in Agrabad, Chattogram, Bangladesh.

This is for a **design hackathon**, so do NOT build a generic furniture e-commerce website. The goal is to create an experience that feels like a **high-end interior design studio** and makes the visitor want to request a consultation.

The brand positioning is:

> **Designed. Crafted. Customized.**

The core idea:

> **Furniture, Crafted Around You.**

---

# 1. IMPORTANT CONSTRAINT

Build **ONE SINGLE LANDING PAGE**, not a multi-page website.

Everything must exist on one scrollable page using sections, anchors, smooth scrolling, modals, drawers, and interactive components.

Do NOT create separate routes for:

* About
* Products
* Services
* Contact
* Gallery
* Pricing

The experience should feel like one carefully art-directed luxury editorial page.

# 21. MOBILE EXPERIENCE

Mobile quality is extremely important.

Do NOT simply shrink desktop.

Design mobile intentionally.

Requirements:

* Excellent typography
* No horizontal overflow
* Touch-friendly interactions
* Proper spacing
* Optimized images
* Sticky consultation CTA
* Fast loading
* Interactive sections must work with touch
* Before/after slider must work on touch
* Design-your-space interaction must work perfectly
* Navigation must become a beautiful mobile menu

On mobile, show a subtle fixed bottom CTA:

**REQUEST CONSULTATION**

---

# 22. ANIMATIONS

Use animation with restraint.

Recommended:

* Smooth page entrance
* Image reveal
* Text reveal
* Fade/slide on scroll
* Image scale on hover
* Elegant card transitions
* Magnetic CTA effect where appropriate
* Before/after drag interaction
* Smooth modal transition
* Navbar transformation on scroll

Avoid:

* excessive bouncing
* flashy neon effects
* excessive particles
* overdone 3D
* animation everywhere

The feeling should be:

**quiet luxury.**

---

# 23. PERFORMANCE

This is critical.

Optimize for:

* Fast initial load
* Lazy-loaded images
* Responsive image sizes
* Minimal JavaScript
* No unnecessary libraries
* Avoid huge video files
* Avoid excessive animation calculations
* Good Lighthouse performance

The page should feel fast even on a mid-range mobile device.

---

# 24. ACCESSIBILITY

Implement:

* semantic HTML
* keyboard navigation
* visible focus states
* proper contrast
* alt text
* accessible buttons
* accessible modal
* reduced-motion support

# 30. FINAL QUALITY BAR

Before considering the page complete, evaluate it as if you are a hackathon judge.

Ask:

### Within 3 seconds:

Can I tell what Heaven Furniture Mart does?

### Within 10 seconds:

Does it feel like a luxury furniture/interior studio?

### Within 30 seconds:

Do I understand why bespoke furniture is different?

### At any point:

Is there a clear next action?

### On mobile:

Does it feel as premium as desktop?

### Overall:

Does this look like a real premium brand or a developer portfolio/template?

The answer must be:

**REAL PREMIUM BRAND.**
